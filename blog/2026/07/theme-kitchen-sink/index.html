Headings and prose

Body copy sits on a measure of about 65 characters, which is the width your eye can track without losing the line. Long-form reading is the whole point, so the measure wins over filling the viewport.

A third-level heading

Inline formatting: bold, italic, inline_code(), a link, and ⌘ + K for keys.

A fourth-level heading

Fourth-level headings are muted, on the theory that if you need four levels the document probably wants splitting anyway.

Code

Fenced blocks get syntax highlighting from Rouge, and stretch past the prose measure on wide screens because code lines are longer than sentences.

def detect_anomaly(flow, threshold=0.87):
    """Score a flow without touching the payload."""
    features = extract_timing_features(flow)  # inter-arrival, burst, direction
    score = model.predict_proba([features])[0][1]

    if score > threshold:
        return Verdict(flow.id, "suspicious", confidence=score)
    return Verdict(flow.id, "benign", confidence=1 - score)
